# Stage-1/2 SRC для Tang Primer 25K (GW5A-LV25MG121NC1/I0)

Вход I2S (slave, 32→16/24/32 внутри) → детект сетки → X1/D2 прямой
повтор/пропуск, X2/X4 — minimum-phase полифазная интерполяция →
огибающая PCM/DSD → silence auto-mute → TPDF-дизер 24→16 → выход I2S
(master, настоящее 16-бит окно) + TDA1541 simultaneous. FIR ФНЧ 8 кГц
УБРАН (был тестом возможностей).

ОДИН образ на оба домена (логика на отношениях к MCLK, абсолютных
частот в RTL нет):
| Вход (от транспорта)            | MCLK      | Выход (MCLK/256) |
|---------------------------------|-----------|------------------|
| 44.1 / 88.2 / 176.4 / 352.8 кГц | 45.1584 МГц | 176.4 кГц      |
| 48 / 96 / 192 / 384 кГц         | 49.152 МГц  | 192 кГц        |

Коэффициент по периоду входного LRCK в тактах MCLK:
128 → ÷2 (отброс каждого 2-го), 256 → x1, 512 → x2 (дубль),
1024 → x4. Переключение после 3 совпадений подряд; мусорный период
игнорируется. Стоп LRCK > 1500 mclk → нули (dithered silence).

## Пины

| Сигнал        | Пин | Примечание                              |
|---------------|-----|-----------------------------------------|
| mclk_in       | C11 | 45.1584 / 49.152 МГц от транспорта     |
| i2s_bclk_in   | C10 | до 24.576 МГц (384k x 64), см. лимит   |
| i2s_lrck_in   | D11 | входная сетка (см. таблицу)             |
| i2s_sdata_in  | B11 | pull-down (стоп = нули, не мусор)       |
| i2s_bclk_out  | E11 | MCLK/8 (6.144 МГц @49.152)              |
| i2s_lrck_out  | A11 | MCLK/256 (192 кГц @49.152)              |
| i2s_sdata_out | K11 | 16 бит, Philips, 16-е слоты             |
| dsd_on        | G11 | pull-down; 1 = native DSD (см. ниже)      |
| dsd_data2_in  | G10 | pull-down; DATA2 второго транспорта       |
| nos_bypass    | A10 | pull-down; перемычка на 3.3V = NOS: движок|
|               |     | X2/X4 выкл, чистой повтор/пропуск на всех  |
|               |     | рейтах. DSD-децимация и дизер не          |
|               |     | отключаются никогда. Переключать на стопе |
|               |     | (на ходу — щелчок ступенькой задержки).   |
| tda_bck_out   | H5  | TDA1541 simultaneous BCK (GCLKT_2)        |
| tda_le_out    | F5  | TDA1541 LE                                |
| tda_dl_out    | G7  | TDA1541 левые данные (offset binary)      |
| tda_dr_out    | H8  | TDA1541 правые данные (offset binary)     |

ЛИМИТ ПРИЁМНИКА: синхронный захват на MCLK надёжен при BCLK ≤ MCLK/4
(проверено: 176.4/192 кГц в 32-битных слотах). 352.8/384 кГц в 32-битных
слотах дают BCLK = MCLK/2 — два отсчёта на бит, запаса нет. Путь ÷2
реализован и замоделирован идеально; на кремнии для 8x-сеток смотреть
STA по i2s_*_in, при проблемах — транспорт в 24-битных слотах
(BCLK = MCLK/2.67, уже терпимо) или IDDR-захват следующим этапом.

## Архитектура

- `i2s_receiver.v` — slave-приёмник, Philips с задержкой 1 BCLK.
  Выход 24 бита, выравнивание по MSB. Слоты 16–32 BCLK.
- `rate_detect.v` — период LRCK в тактах MCLK → sel (D2/X1/X2/X4),
  3 совпадения на переключение, in_idle при простое.
- `src_dupdrop.v` — повтор/пропуск: на старте выходного кадра защёлкнуть
  последнюю входную пару каждый R-й кадр (R=1/2/4), иначе повторить.
  L/R атомарно, парность по построению. Задержка 1 кадр (~5 мкс).
  Крутится всегда (выход движка или его — мультиплексор `use_engine`).
- `src_interp.v` — движок X2/X4: ОДИН общий 24x32 MAC + 64-бит аккумулятор,
  тайм-мультиплекс 2 канала x 31 тап (~70 mclk на кадр из 256).
  Скалярные истории + case-ROM `{rom_set, phase, tap}` (никаких
  динамических индексов — иначе $mem и расхождение sim/silicon).
  X2: minimum-phase N=33 (17 тапов/фаза, паддинг нулями до 31), полоса
  0–20 кГц ripple 0.005 дБ, переход 20→44.1k, стоп 83.8 дБ от Найквиста
  входа (44.1k @176.4 / 48k @192) — настоящий интерполятор: образы
  контента 20…48k лежат в стопе, а не в переходе (старый gentle N=25
  останавливал только от 68/76k: −19 дБ образа на тоне 40k, LA-доказано).
  X4: N=121 (31 тап/фаза), ripple 0.09 дБ, стоп 59.7 дБ от 24.1k.
  Оба — ZERO precursor (neg-precursor 0.00%, прешута степа 0).
  Коэффициенты Q2.30, DC точен по построению (`tools/design_interp.py` —
  единый источник для ROM и hex для бенчей). Переполнение на горячих
  переходных — сатурация в рейлы S24 (не врап); устоявшиеся синусы
  полной шкалы не клиппуют. `bypass=1` (джампер A10) гасит движок,
  выход — чистой dup/drop.
- Огибающая PCM/DSD в `top.v`: спад 128 кадров → мукс на нуле гейна →
  холд 2^18 MCLK → подъём 1024 кадра (см. раздел DSD). Оба фейд-мульта —
  ручные LUT shift-add деревья, бит-идентичны $mul: инференые 24x11
  мульты дважды умирали на кремнии точным нулём (сначала R, потом L
  после пересборки — класс DSP-mapping/config-spot, сим-слепой, все
  отчёты идеальны). Каналы структурно симметричны, лотереи DSP-спотов
  больше нет. Плюс регистр-тайминг-труба данных+валида (P&R worst setup
  был 0.039 нс — мульт/дерево фейда + сумматор дизера в одном MCLK).
- `silence auto-mute` в `top.v`: 4095 нулевых пар (~23 мс) → точный
  0x0000 после дизера (TPDF ±1 LSB в стопе виден на LA); любой ненулевой
  сэмпл снимает мгновенно; старт с POR в мьюте.
- `dither_24_16.v` — стерео S24→S16 с TPDF 1 LSB (сумма двух независимых
  16-битных LFSR на канал; L/R — разные сиды). Перед дизером запас
  safe = x − (x>>>13) (−0.00106 дБ): легальный 0 dBFS на ±32763…32765,
  насыщения нет по построению, клампа нет специально.
- `i2s_transmitter.v` — master 16-битных слотов (BCLK=MCLK/8,
  LRCK=MCLK/256) + frame_tick для SRC. L и R кадра — из одного снапшота.
- `top.v` — связь + power-on reset (внешнего ресета нет).

## Native DSD (Amanero-стиль, dsd_on=1 на G11)

В DSD-режиме транспорт гонит бит-клок на BCLK (C10, 2.8224…22.5792 МГц),
DATA1 на SDATA (B11), DATA2 на LRCLK (D11, Amanero) или на выделенный
пин G10 (второй транспорт, pull-down). `dsd_data2_in` автовыбирает живой
источник (≥16 переключений на границах DSD-битов за ~1 мс, иначе LRCLK;
перевооружение каждую сессию в idle). Цепочка:
`dsd_to_pcm.v` (1024-tap windowed-sinc FIR на 1-битных тапах = сложение/
вычитание коэффициентов, без умножителей; автовыбор децимации /8…/64 по
замеру периода бит-клока) →
352.8 кГц S32 → `dsd_pcm_decim2.v` (Kaiser /2, 128 тапов) → 176.4 кГц S32
→ `dsd_round_s32_s24.v` (round-half-up + сатурация в S24) → тот же TPDF
и TX. Замер на железе (2026-09-09): транспорт отдаёт RIGHT по SDATA и
LEFT по LRCLK — top.v меняет их местами, чтобы DSD L/R совпал с PCM.
Модули DSD — дословная копия проверенного тракта из /mnt/sdb/fpga
(`diff` пуст); мультиплексор PCM/DSD только переключает источник, обе
цепочки крутятся постоянно, а момент переключения идёт через огибающую:
по фронту dsd_active — спад 128 кадров на старом источнике, переключение
мукса на нуле гейна, холд нулей 2^18 MCLK (~5.8 мс: DSD проходит
acquisition + заполнение FIR-окна, PCM — релок детекта + промывку
историй), подъём 1024 кадра на новом. Без огибающей сама ступенька
музыка↔тишина — щелчок в полный масштаб; шторка-тишина одна его не
убирает (проверено на железе). Возврат PCM после потопа — по
конструкции (флуд-бенч), без производных ресетов: производный асинхронный
ресет PCM-ветки на кремнии убил PCM полностью при живом DSD (симуляция
этого класса не видит) — откачен, единый проверенный POR-ресет.

Требование: DSD — только при MCLK 45.1584 МГц (рейты DSD — семейство
44.1, выходная сетка фиксирована MCLK/256 = 176.4 кГц). PCM-тракт в DSD
режиме видит мусор на LRCK — его выход игнорируется мультиплексором.
Честные границы: DC-усиление каскада 2^31−8 (не ровно 2^31 — квант
коэффициентов Kaiser), поэтому честный +FS DSD упирается в рейл S24 ровно
через сатурацию (не врап — доказано бенчем); тишина чередующихся бит —
остаток 0 LSB24 (мерено).

ВАЖНО (2026-09-08, исправлено): `dsd_round_s32_s24.v` сравнивал
НЕСДВИНУТОЕ Q31-значение с рейлами S24. Любой нормальный музыкальный
уровень выше ~−48 dBFS зажимался в рейл — это и есть «лес гармоник»
в DSD-режиме. DC-прогоны (все единицы/нули) этот дефект не видят:
они стоят на рейле по построению. Исправлено: сдвиг >>>8 до сатурации
(S24-шкала) + регресс `tb/tb_dsd_round_s32_s24.v` (0, ±1/8…1/2 FS
проходят без рейла, рейлы насыщаются, полбита круглится вверх).

Тестовый FIR ФНЧ 8 кГц и его бенчи полностью удалены из дерева
(история git их помнит); в сборке только тракт ниже.

## Сборка в Gowin IDE (Windows)

1. Устройство GW5A-LV25MG121NC1/I0, язык Verilog 2001.
2. Добавить файлы: `top.v`, `i2s_receiver.v`, `rate_detect.v`,
   `src_interp.v`, `src_dupdrop.v`, `dither_24_16.v`, `i2s_transmitter.v`,
   `tda1541_tx.v`, `dsd_to_pcm.v`, `dsd_pcm_decim2.v`, `hb_sample_ram.v`,
   `dsd_round_s32_s24.v` + КОПИЮ `tools/interp_coefs.vh` рядом с RTL
   (verilog `include). `tools/gowin_sdpb_bb.v` — только для локального
   гейта yosys (blackbox SDPB); в Gowin НЕ добавлять (там свой примитив
   из библиотеки). `gowin_bsram_sim.v` — только для icarus-симуляции,
   в Gowin НЕ добавлять.
   Старый `top.v` заменить целиком.
3. Констрейнты: `fir.cst` (`dsd_on` G11, `dsd_data2_in` G10,
   `nos_bypass` A10 — все с pull-down; TDA1541: BCK H5, LE F5, DL G7,
   DR H8), `constraints.sdc`.
   MCLK от транспорта (45.1584/49.152) — в SDC забит tight-вариант
   49.152. DSD — только при 45.1584. ВАЖНО: `src_interp.v` инклудит
   `tools/interp_coefs.vh` — в проект класть СВЕЖУЮ КОПИЮ рядом с RTL (stale-копия = старый фильтр при новом остальном: прошлая сборка
   молча повезла gentle-X2 вместо N=33, поймано LA-замером).
4. Синтез → P&R → прошить. Проверить положительный setup/hold slack
   (особо входной BCLK на 8x-сетках) и ресурсы: 3 умножителя (1 движок
   интерполяции 24x32 + 2 MAC 32x32 дециматора DSD; оба фейда 24x11 —
   ручные LUT shift-add, бит-идентичны) и 10 блоков
   BSRAM
   (8 коэффициенты DSD-FIR + 2 линии задержки). В отчёте Gowin top-level
   DSP обязано упасть на 1 против сборки с DSP-фейдами — иначе дерево
   перепаковалось в DSP и увёртка не сработала.

## Локальная проверка

`make verify` — четырнадцать бенчей (сквозной I2S X1: Philips-кадр, плоские
1/8/30 кГц, L−R < 2 LSB, детект X1; матрица SRC D2/X1/X2/X4 + фазы +
глитч + idle-mute + relock; контракт дизера (рейлы/headroom, границы,
белизна: mean/дисперсия/lag-1/L-R кросс на 65536 парах тишины);
бит-точный движок интерполяции X2/X4: импульсы/DC/степы/синусы/X1 +
NOS-байпас (бит-импульс: ровно 2 фрейма со значением, остальное нули —
доказывает что движок реально выключен, а не притих); DSD-тракт: гейт,
DC-рейлы на DSD64…512, роутинг DATA2 с LRCLK, тишина, сквозной прогон
через top до слов I2S; S32→S24 round: x2 (+6 dB DSD, коммерческий паритет громкости):
малые уровни удваиваются, ±1/2 FS садятся на рейлы, рейлы насыщаются; переход PCM→DSD→PCM через top:
своп L/R, огибающая без клик-ступеньки (макс-шаг << FS) и с реальным
тихим холдом в обе стороны, PCM оживает с теми же уровнями; потоп:
PCM выживает под DSD-клоком+мусором на общих пинах, возврат поканально
тот же) и elaboration yosys (ровно 3 умножителя, 10 SDPB, 0 памятей).
Девятый — `tb_swap_diag`: два инстанса top на одном стерео-стимуле,
swap=1 обязан выдать слоты с обменом (допуск ±2 LSB дизера/фазы
захвата; роутинг доказан разнесёнными на 0.5 FS паттернами каналов).
Параметр top `DIAG_SWAP_TX=1` — кремниевая биссектриса немого правого:
тишина переехала влево — бэкенд (TX) цел, ноль из фронтенда; тишина
осталась справа — виновата правая половина TX. По умолчанию 0,
бит-идентично (гейт 4/10 держится).
Десятый — `tb_chatter`: регрессия дебаунсера `DB_BITS` (окно 2^DB:
~47 мс на кремнии при 21, 64 такта в бенчах): поддребезговый дребезг
dsd_on не срывает STEADY PCM и не глушит музыку, устойчивая единица
переключает мукс, дребезг вокруг единицы держит, устойчивый ноль
возвращает. Fail-safe: линия, которая так и не успокоилась, держит
последний принятый уровень (после POR: PCM).
Одиннадцатый — `tb_dsd_hostile`: кремниевая реальность перехода
(поймал посмертный клин PCM после DSD, LA-доказано: вход валидный
44.1 кГц, выход дизерные нули, сетка цела). PCM 44.1 кГц (X4-движок)
→ пауза клоков → асинхронный DSD-эпизод со своим кварцем (дрейф фазы
битклока, LFSR-мусор 50% плотности на общих пинах) → пауза → возврат
PCM. Требует: STEADY, мукс на PCM, валиды текут и Means вернулись к
±0.25 FS. Регрессия бага `zero_frame`: флаг был write-once (сброс
только POR) — после любой паузы клоков движок X2/X4 вечно выдавал
валидные нули с замороженной фазой; лечится только перепрошивкой.
Фикс: `zero_frame` — per-job флаг (`src_interp.v`, S0).
Двенадцатый — `tb_tda`: TDA1541(A) simultaneous-выход (`tda1541_tx.v`,
пины BCK H5 / LE F5 / DL G7 / DR H8). Функционал по miro1360/MT02:
16-битные слова L+R параллельно, MSB-first, инвертированный MSB
(offset binary), 16 остановленных BCK на сэмпл, LE-импульс 4 BCK
после последнего бита, иначе BCK в нуле. В отличие от референса
(ресинхронизация входного 64fs I2S), блок — мастер от своих
MCLK/frame_tick и питается той же пост-дизерной 16-битной парой,
что I2S TX (прямой маппинг, DIAG_SWAP_TX не действует): оба выхода
всегда согласны. Юнит: все слова/рейлы/голод-повтор; сквозной:
X1 DC ±0.25 FS декодируется в offset-binary ±16 LSB.
Тринадцатый — `tb_mute`: silence auto-mute (грязь TPDF ±1 LSB в стопе
на LA). 4095 нулевых пар подряд (~23 мс) → точный 0x0000 после дизера
на оба выхода (I2S и TDA); любой ненулевой сэмпл снимает мгновенно;
старт с POR в мьюте; синус не триггерит (1-2 нулевых сэмпла на кросс);
холд переключения (~1024 нулевые пары) ниже порога — огибающая
не тронута. Сенс до дизера (точные нули), гейт после.
Четырнадцатый — `tb_dsd_srcsel`: автовыбор источника DATA2
(`dsd_data2_in`, пин G10 с pull-down). Amanero (DATA2 на LRCLK,
пин висит в нуле) → LRCLK; второй транспорт (DATA2 на пине,
LRCLK статичен) → пин; редкие наводки (< 16 переключений за ~1 мс)
не угоняют; idle (dsd_on=0) перевооружает решение каждую сессию.
Детект только по переключениям на границах DSD-битов. Юнит-истина
(SDATA→stage-L) + точные рейлы/тишина во всех ветках.

## Кремниевые доказательства (LA, декод DATA_out+I2S)

- X2 gentle N=25 (старый): тон 40 кГц −6 dBFS @96k → образ 56k
  подавлен на 18.8 дБ против теории ROM 17.6 дБ (движок/фазы/кремний
  верны, дизайн gentle — стоп только от 68/76k). Посемпльно против
  идеальной модели: невязка 0.50 LSB при поле дизера 0.41 —
  интерполяция точна до долей LSB.
- X2 N=33 (нынешний): тот же тон → подавление 67.3 дБ против теории
  67.34 дБ, оба канала (LA-захват декодирован пословно).
  A/B джампером на тоне: +17 дБ (движок −25.2 / дубль −8.6 = 16.6
  по теории) — независимое подтверждение живого ROM на кремнии.
- X1: фундамент 1:1, образа нет, каналы симметричны — прозрачность.
- Фейды: инференые 24x11 мульты умирали точным нулём дважды (R, затем
  L после пересборки; сигнатура — нули + живой дизер ±1 LSB, сим-слепо).
  Оба — LUT-деревья, каналы симметричны. Slack сборок: был 0.039 нс,
  стал 3.688 нс.
- Дизер: TPDF ±1 LSB, lag-1 ~0.002, спектр плоский, L/R независимы
  (мегадамп из RTL + tb-ассёрты белизны).
